# tallyatom

Tally HTML/Markdown atom fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/tallyatom/

## Install / run

```bash
git clone https://github.com/theworker02/tallyatom.git
cd tallyatom
node src/cli.js
node --test
```
